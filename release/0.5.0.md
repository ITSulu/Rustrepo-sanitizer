# Rustrepo-sanitizer 0.5.0

## Summary

Rustrepo-sanitizer 0.5.0 creates deterministic, sanitized AI review bundles from
Git repositories. This feature release completes hover help across the native
GUI and presents the command-line help as clear, purposeful groups that mirror
the capabilities the GUI exposes.

## Features

- Every GUI input, field label, checkbox, selector, and button now shows a
  plain-language tooltip after a short hover dwell, across the main, settings,
  about, and help windows. Tooltips disappear when the pointer leaves and never
  block keyboard or mouse use.
- The GUI and CLI draw their wording from one shared description source
  (`src/help.rs`), so help text cannot drift between the two frontends.
- The CLI help is regrouped into Repository / input, Output, Archive /
  compression, Include / exclude, Redaction / sanitization, Reports / metadata,
  Security / password, and Advanced sections, with one short description per
  argument.
- `--help`, `-h`, and `-help` all print help and exit successfully at the top
  level and on the `sanitize` subcommand.

## Bug Fixes

- Fixed a CLI help regression where every `sanitize` option was rendered
  without any description.
