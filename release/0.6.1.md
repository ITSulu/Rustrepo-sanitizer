# Rustrepo-sanitizer 0.6.1

## Summary

Rustrepo-sanitizer 0.6.1 is a unified-binary architecture correction. The
separate `rustrepo-sanitizer-web` executable is removed; a single
`Rustrepo-sanitizer` executable now provides the CLI, the desktop GUI, and the
web UI:

- `Rustrepo-sanitizer` (no mode flag) — the sanitize CLI and `list-formats`.
- `Rustrepo-sanitizer --gui` — the desktop GUI only.
- `Rustrepo-sanitizer --web` — the web UI and HTTP API only.
- `Rustrepo-sanitizer --gui --web` — both run in one process; neither blocks the
  other, and closing the GUI shuts the web server down cleanly.

GUI + Web runs a single process (the web server on a background thread, the GUI
on the main thread); no helper executable is spawned. All three interfaces keep
using the shared sanitizer core.

## Features

- One `Rustrepo-sanitizer` executable for CLI, GUI, and web, replacing the
  separate web binary.
- Grouped top-level help documents the launch modes and the web bind, auth, and
  integration options; `--help`, `-h`, and `-help` all work.
- Web options (`--web-bind`, `--web-token`, `--web-root`, `--web-local-roots`,
  `--web-forgejo-base`, `--web-forgejo-token`, `--web-github-api`,
  `--web-github-token`) are available when web mode is enabled and fall back to
  the existing `RUSTREPO_WEB_*` environment variables.
