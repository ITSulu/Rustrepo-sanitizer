# Rustrepo-sanitizer 0.2.0


## Features

- Adds deterministic repository-and-revision-based default archive names.
- Adds regression coverage for preserving useful repository context while
  redacting high-confidence credentials.

## Bug Fixes

- Improves redaction precision for paths, URLs, Markdown links, schema keys,
  environment references, and Kubernetes or secret-store symbolic references.
- Reduces false positives that previously removed useful repository context.
- Makes default archive names stable for repeatable reviews and automation.

## Verification

- Review the generated report and sanitized archive before distribution.
- Confirm that sensitive values are removed while non-sensitive context remains.
