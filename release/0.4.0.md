# Rustrepo-sanitizer 0.4.0

## What changed

This release improves the Slint GUI’s accessibility and interaction contract.
Advanced controls remain present in the accessibility tree, nested menu entries
are discoverable through AT-SPI, and the maximize/resize behavior is checked
against the native GUI harness rather than inferred from internal state. The
GUI test path also waits for controls to materialize before inspecting them,
which makes the accessibility checks deterministic on CI workers.

## Verification

- Forgejo Actions quality, stable-check, GUI accessibility, and security jobs
  passed on the Garuda rootless-Podman runner.
- The exact `v0.4.0` tag was used to build the Linux x86_64 archive, Debian
  package, and RPM package.
- `SHA256SUMS` covers every published asset and is checked before and after
  publication.

## Downloads

The release includes a Linux x86_64 `.tar.gz` archive, `.deb`, `.rpm`, and
`SHA256SUMS`. Verify the downloaded file against the matching manifest before
installing or extracting it.
