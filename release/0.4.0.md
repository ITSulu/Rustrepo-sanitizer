# Rustrepo-sanitizer 0.4.0

## Summary

Rustrepo-sanitizer 0.4.0 creates deterministic, sanitized AI review bundles from
Git repositories. It is the first 0.4.x release and introduces the GUI
accessibility work that the 0.4.x line builds on.

## Features

- Keeps advanced GUI controls present in the accessibility tree so keyboard and
  assistive-technology users can discover the complete workflow.
- Exposes nested menu entries through AT-SPI, including controls that are not
  visible in the initial window layout.
- Checks maximize and resize behavior through the native GUI harness and waits
  for controls to materialize before inspection, making accessibility checks
  deterministic on CI workers.

## Bug Fixes

- Fixed GUI accessibility checks that could pass from internal state while the
  native window did not exhibit the required observable behavior.
- Fixed timing-sensitive control discovery in the GUI test path.

## Verification

- Forgejo Actions quality, stable-check, GUI accessibility, and security jobs
  passed on the Garuda rootless-Podman runner.
- The exact `v0.4.0` tag was used to build every published artifact.
- `SHA256SUMS` covers every published asset and is checked before and after
  publication.
- No issue is closed by this release.

## Downloads

The release includes Linux glibc and musl archives for x86_64 and aarch64,
Alpine archives for x86_64 and aarch64, a Debian package, an RPM package, an
Arch package, a Windows x86_64 ZIP, and `SHA256SUMS`. Verify each download
against the matching manifest entry before installing or extracting it.
