# Rustrepo-sanitizer 0.6.3

This release improves the Web and desktop interfaces and makes CLI-only,
non-interactive sanitization workflows easier to discover and verify.

## Web interface

- Top navigation opens distinct Sanitize, Option Reference, and About views.
- About uses the same product, license, credits, links, version, and build-date
  metadata as the desktop GUI's Help → About window.
- Include and Exclude preset selectors have room for common choices. Adding and
  removing preset and custom patterns updates the submitted filter list.

## Desktop GUI

- The Output File path expands to use the available row space before Browse.
- Field labels use light grey text against the dark form background.

## CLI

- --help and -h show grouped arguments, descriptions, accepted size units,
  and a complete command-line-only example.
- A regression workflow creates and inspects a sanitized archive with stdin
  closed, including filtering, untracked-file handling, report selection, and
  output naming.

## Verification

- Rust tests cover CLI behavior and help, Web server-rendered output, interface
  metadata parity, and GUI style/layout contracts.
- Playwright covers view navigation, About content, readable preset controls,
  and Include/Exclude Add/Remove behavior.
- Release artifacts use the standard unified-binary matrix and SHA256SUMS.
