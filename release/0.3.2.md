Release 0.3.2

This release adds reproducible cross-platform binary archives and native Linux
package artifacts where the corresponding packaging toolchain is available.
Every published file is listed in `SHA256SUMS` and is verified before and
after publication to Forgejo and GitHub.

Linux aarch64, macOS arm64/x86_64, and Windows x86_64 archives are built on
native runners. Debian/Ubuntu, Fedora/RHEL, and Arch packages are built in
their matching Linux environments. Alpine `.apk` is not included because this
project does not currently maintain an Alpine `abuild` signing key or a
validated musl package repository; the generic Linux archive is the supported
Alpine installation path until that infrastructure exists.
