# Rustrepo-sanitizer 0.3.2

## Features

- Adds reproducible release-artifact packaging for the Linux x86_64 archive,
  Debian package, and RPM package.
- Adds idempotent Forgejo/GitHub release synchronization tooling.
- Adds installation guidance for release archives and native packages.

## Bug Fixes

- Fixes repeated publication so an existing release can be reconciled without
  duplicating assets or changing the exact tag provenance.

## Verification

- The exact tag is used for artifact generation, and `SHA256SUMS` covers every
  published asset.
- Verify each downloaded asset against the matching checksum before use.
