# Rustrepo-sanitizer 0.3.0

## Features

- Adds sanitized chronological Git history to generated archives.
- Adds timestamped and CI-stable default archive names.
- Adds ZIP, 7z, and multiple TAR compression selections with explicit backend
  capability reporting.
- Adds ZIP AES-256 password input from a file or standard input.

## Bug Fixes

- Fixes ambiguous archive naming in automated workflows by providing stable
  repository-and-revision naming options.
- Reports unavailable compression backends explicitly instead of silently
  selecting an unexpected format.

## Verification

- Confirm the selected archive backend is available before packaging.
- Verify release assets against the published checksum manifest before use.
