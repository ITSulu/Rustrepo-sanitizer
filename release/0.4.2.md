# Rustrepo-sanitizer 0.4.2

## Features

- Completes the 0.4.x GUI accessibility work with advanced controls retained in
  the accessibility tree.
- Covers nested menu entries with AT-SPI checks so the full menu hierarchy is
  discoverable by assistive-technology clients.
- Preserves the existing TDD workflow and passing 77-test baseline.

## Bug Fixes

- Fixed the maximize contract to use observable native GUI behavior rather than
  an internal state assumption.
- Fixed accessibility regressions that hid advanced controls or nested menu
  entries from clients.

## Verification

- The merged 0.4.2 pull request passed the required Forgejo Actions checks,
  including GUI accessibility and security validation.
- The exact `v0.4.2` tag was used to build the Linux x86_64 archive, Debian
  package, and RPM package.
- `SHA256SUMS` covers every published asset and is checked before and after
  publication.
