# Rustrepo-sanitizer 0.4.2

## What changed

This release completes the GUI accessibility work for the 0.4.x series.
Advanced controls are kept in the accessibility tree, nested menu entries are
covered by the AT-SPI checks, and the maximize contract is tested through
observable native GUI behavior. The change preserves the existing TDD work
and passing 77-test baseline while making the advanced controls usable by
assistive-technology clients.

## Verification

- The merged 0.4.2 pull request passed the required Forgejo Actions checks,

- The exact `v0.4.2` tag was used to build the Linux x86_64 archive, Debian
  package, and RPM package.
- `SHA256SUMS` covers every published asset and is checked before and after
