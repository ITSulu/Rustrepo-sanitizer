# Rustrepo-sanitizer 0.4.1

## Features

- Carries the 0.4.x GUI accessibility improvements into the maintenance line.
- Keeps advanced controls and nested menu entries visible to AT-SPI clients.
- Validates the maximize contract through observable native window behavior.

## Bug Fixes

- Fixed GUI checks that relied on internal maximize state instead of the
  behavior visible to the native test harness.
- Fixed control-query races by waiting for controls to become available before
  inspecting the accessibility tree.

## Verification

- Forgejo Actions quality, stable-check, GUI accessibility, and security jobs
  passed on the Garuda rootless-Podman runner.
- The exact `v0.4.1` tag was used to build the Linux x86_64 archive, Debian
  package, and RPM package.
- `SHA256SUMS` covers every published asset and is checked before and after
  publication.

## Downloads

The release includes a Linux x86_64 `.tar.gz` archive, `.deb`, `.rpm`, and
`SHA256SUMS`. Verify the downloaded file against the matching manifest before
installing or extracting it.
