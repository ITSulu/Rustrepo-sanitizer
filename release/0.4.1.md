# Rustrepo-sanitizer 0.4.1

## What changed

This maintenance release carries the GUI accessibility improvements from the
0.4.x line and aligns the maximize contract with the native test harness.
Advanced controls and nested menu entries remain visible to AT-SPI clients,
while the GUI checks validate observable window behavior and wait for the
controls to become available before querying them. The result is a more stable
and reviewable accessibility path for keyboard and assistive-technology use.

## Verification

- Forgejo Actions quality, stable-check, GUI accessibility, and security jobs
  passed on the Garuda rootless-Podman runner.
- The exact `v0.4.1` tag was used to build the Linux x86_64 archive, Debian
  package, and RPM package.
- `SHA256SUMS` covers every published asset and is checked before and after
  publication.

## Downloads

The release includes a Linux x86_64 `.tar.gz` archive, `.deb`, `.rpm`, and
`SHA256SUMS`. Verify the downloaded file against the matching manifest before
installing or extracting it.
