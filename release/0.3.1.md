# Rustrepo-sanitizer 0.3.1

## Features

- Includes every unique commit reachable from local refs in the generated Git
  chronology, including unmerged and tag-only histories.
- Orders the chronology deterministically using topological ordering.

## Bug Fixes

- Fixes incomplete history reports that omitted commits available only from
  unmerged branches or tags.
- Sanitizes commit subjects in the generated chronology so repository metadata
  does not reintroduce sensitive content.

## Verification

- Generated history is deterministic for the same repository and revision.
- Verify release assets against the published checksum manifest before use.
